# XASP 1.8.0 — Governed 2% Target Reset

The governed objective is now an XRP upside move of at least 2%.

- Model B uses `UP_02`, `DOWN_02`, and `NO_EVENT` first-touch classes.
- Model A retains full future-excursion quantile forecasts and explicitly
  evaluates whether the +2% target is reached by its median and upper estimate.
- Target definition version
  `xrp-symmetric-first-touch-2pct-v1` is persisted in both model families.
- Existing ±10% anchors, models, reports, and predictions are invalidated once.
- Raw observed Binance candles and their ingestion watermarks are preserved.

The first post-upgrade run rebuilds target-derived partitions and retrains both
model families before any new research result can become available.
